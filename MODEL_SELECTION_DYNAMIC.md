# Model Selection Dynamic Loading - Implementation Summary

## Overview
Converted the hardcoded AI model dropdown to a dynamic system that loads models from `model-config.ts`, allowing easy model management and switching.

## Changes Made

### 1. Created `model-config-export.cjs`
**Location:** `buddy/frontend/src/lib/ai/model-config-export.cjs`

- CommonJS export file for Electron main process compatibility
- Synced with `model-config.ts` to maintain single source of truth
- Exports all available AI models (Google Gemini, OpenAI, Anthropic, OpenRouter)
- Provides utility functions: `getAllModels()`, `getModelsByProvider()`, `getModelById()`

### 2. Updated `chat-input.html`
**Changes:**
- Removed all hardcoded model dropdown items (~140 lines of HTML)
- Kept only the dropdown container structure
- Added comment: "Model items will be dynamically generated by model-selection.js"
- Changed model selection button from `icon-only` to `with-text` class
- Added `<span id="selectedModelName">` to display current model name in button

### 3. Enhanced `model-selection.js`
**Location:** `buddy/chat-input/modules/model-selection.js`

Updated `updateModelButtonState()` function to:
- Update the button title with current model name
- Dynamically update the `selectedModelName` span element
- Show the selected model name in the UI

## How It Works

### Model Loading Flow:
1. **Main Process** (`main.js`):
   - IPC handler `get-all-ai-models` loads models from `model-config-export.cjs`
   - Returns available models to renderer process

2. **Renderer Process** (`model-selection.js`):
   - `initializeModelSelection()` fetches models via `window.chatInputAPI.getAllAIModels()`
   - `renderModelDropdown()` dynamically generates HTML for each model
   - Groups models by provider (Google, OpenAI, Anthropic, OpenRouter)
   - Displays features, costs, and capabilities for each model

3. **User Interaction**:
   - User clicks model selection button → dropdown appears
   - User selects a model → `selectModel(modelId)` is called
   - Model name updates in button → selection saved to localStorage
   - Main process notified via IPC

## Benefits

✅ **Single Source of Truth**: All models defined in `model-config.ts`
✅ **Easy to Extend**: Add new models by editing only `model-config.ts` and `model-config-export.cjs`
✅ **Dynamic UI**: No hardcoded HTML, models render automatically
✅ **Visual Feedback**: Button shows currently selected model name
✅ **Persistent Selection**: Choice saved to localStorage
✅ **Provider Grouping**: Models automatically grouped by provider

## Adding New Models

To add a new model, update both files:

1. **Add to `model-config.ts`**: Add to `AVAILABLE_MODELS` array
2. **Add to `model-config-export.cjs`**: Add to `AVAILABLE_MODELS` array (keep in sync)
3. Set `isAvailable: true` for active models
4. The UI will automatically display the new model!
