# YouTube Transcript Module

A TypeScript module for extracting transcripts from YouTube videos. Built with **SOLID principles** for maintainability and extensibility.

## Features

- ✅ Extract video ID from any YouTube URL format
- ✅ Fetch player response via Innertube API with HTML fallback
- ✅ Parse caption tracks from player response
- ✅ Prefer manual captions over auto-generated (ASR)
- ✅ Download subtitles in multiple formats (JSON3, VTT, SRT, TTML)
- ✅ Parse captions into clean text with optional timestamps
- ✅ Handle errors (no subtitles, private/age-restricted videos)
- ✅ IPC handlers for Electron main process communication
- ✅ Full TypeScript support with type definitions
- ✅ Dependency injection for testing and customization
- ✅ No video file downloads
- ✅ No YouTube Data API required

## Architecture

This module follows **SOLID principles**:

- **Single Responsibility**: Each class has one specific job
- **Open/Closed**: Extensible via interfaces and strategy pattern
- **Liskov Substitution**: All implementations are interchangeable
- **Interface Segregation**: Small, focused interfaces
- **Dependency Inversion**: Services depend on abstractions

## Quick Start - API Usage

### Class-based API (Recommended)

```typescript
import { YouTubeTranscriptAPI } from './youtube-transcript';

// Get transcript
const result = await YouTubeTranscriptAPI.getTranscript('https://youtube.com/watch?v=VIDEO_ID');

if (result.success) {
  console.log('Text:', result.data.text);
  console.log('Language:', result.data.language.name);
  console.log('Auto-generated:', result.data.language.isAutoGenerated);
}

// With options
const result = await YouTubeTranscriptAPI.getTranscript(url, {
  includeTimestamps: true,
  language: 'en'
});

// Get just the text (convenience method)
const text = await YouTubeTranscriptAPI.getText('VIDEO_URL');

// Check if captions exist
const hasCaptions = await YouTubeTranscriptAPI.hasCaptions('VIDEO_URL');

// Get available languages
const languages = await YouTubeTranscriptAPI.getLanguages('VIDEO_URL');

// Validate URL
const validation = YouTubeTranscriptAPI.validate('VIDEO_URL');
console.log(validation.videoId); // Extracted video ID

// Extract video ID
const videoId = YouTubeTranscriptAPI.extractVideoId('https://youtu.be/dQw4w9WgXcQ');
```

## API Reference

### YouTubeTranscriptAPI

| Method | Description | Returns |
|--------|-------------|---------|
| `getTranscript(url, options?)` | Get full transcript with metadata | `APIResponse<TranscriptData>` |
| `getText(url, options?)` | Get just the transcript text | `string \| null` |
| `getLanguages(url)` | Get available caption languages | `APIResponse<LanguageInfo[]>` |
| `hasCaptions(url)` | Check if video has captions | `boolean` |
| `validate(url)` | Validate URL and extract video ID | `ValidationResult` |
| `extractVideoId(url)` | Extract video ID from URL | `string \| null` |
| `getRawTranscript(url, options?)` | Get full raw service response | `TranscriptResult` |

### TranscriptAPIOptions

```typescript
interface TranscriptAPIOptions {
  includeTimestamps?: boolean;  // Include timestamps in text
  language?: string;            // Preferred language code
}
```

### TranscriptData

```typescript
interface TranscriptData {
  text: string;                 // The transcript text
  videoId: string;              // YouTube video ID
  language: {
    code: string;               // e.g., 'en'
    name: string;               // e.g., 'English'
    isAutoGenerated: boolean;   // true if ASR
  };
  availableLanguages: LanguageInfo[];
  trackCount: number;
}
```

### APIResponse

```typescript
interface APIResponse<T> {
  success: boolean;
  data?: T;
  error?: string;
}
```

## Feature Integration Example

```typescript
// In your feature file
import { YouTubeTranscriptAPI } from '../youtube-transcript';

export async function processYouTubeVideo(url: string) {
  // Validate first
  const validation = YouTubeTranscriptAPI.validate(url);
  if (!validation.valid) {
    throw new Error('Invalid YouTube URL');
  }

  // Check for captions
  if (!await YouTubeTranscriptAPI.hasCaptions(url)) {
    throw new Error('No captions available');
  }

  // Get transcript
  const result = await YouTubeTranscriptAPI.getTranscript(url);
  if (!result.success) {
    throw new Error(result.error);
  }

  // Use the transcript
  return {
    videoId: result.data.videoId,
    transcript: result.data.text,
    language: result.data.language.name,
  };
}
```

## Error Handling

The service handles various error scenarios:

- **Invalid URL**: Returns error for invalid YouTube URLs
- **Video Not Found**: Handles 404 errors (deleted/private videos)
- **Access Denied**: Handles 403 errors (age-restricted/private videos)
- **No Captions**: Returns error if no captions are available
- **Network Errors**: Handles network failures gracefully
- **Parse Errors**: Handles JSON parsing and subtitle parsing errors

## Notes

- The module does NOT download video files
- The module does NOT use YouTube Data API
- Uses Innertube API with HTML fallback for reliability
- Manual captions are preferred over auto-generated (ASR) captions
- English is preferred if multiple languages are available
- Timestamps can be included in the transcript output
- Full TypeScript support with type definitions

## Limitations

- Requires the video to have captions/subtitles available
- May break if YouTube changes their API/HTML structure
- Some private or age-restricted videos may not be accessible
- Rate limiting may apply if making too many requests
