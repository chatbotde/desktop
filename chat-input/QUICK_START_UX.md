# Quick Start Guide - Enhanced UX Features

Welcome to the improved chat-input-container! This guide will help you get started with all the new UX enhancements.

---

## 🚀 Getting Started

### First Time Users

1. **Launch the application** - The chat input will appear in its collapsed state
2. **See the help hint** - A small tooltip appears showing you can press `Ctrl+/` for shortcuts
3. **Start typing** - Just start typing anywhere to focus the input
4. **Expand when needed** - Press `Ctrl+E` or click the expand button for multi-line input

---

## ⌨️ Most Useful Shortcuts

### Essential Shortcuts (Learn These First!)

```
Ctrl+Z        → Undo your last action
Ctrl+Y        → Redo what you undid
Ctrl+A        → Select all text
Ctrl+E        → Expand/Collapse the input
Ctrl+/        → Show all keyboard shortcuts
```

### Everyday Shortcuts

```
Enter         → Send message (collapsed mode)
Shift+Enter   → Send message (expanded mode)
Escape        → Clear selection or collapse
Ctrl+H        → Hide window
```

---

## 📝 Text Editing Features

### Undo/Redo

**Works on everything:**
- ✅ Text you type
- ✅ Text you paste
- ✅ Text you delete
- ✅ Attachments you add
- ✅ Attachments you remove

**Try it:**
1. Type something: "Hello world"
2. Delete it: Select all (`Ctrl+A`) and delete
3. Undo: Press `Ctrl+Z` - Your text is back!
4. Redo: Press `Ctrl+Y` - Gone again!

### Smart Text Selection

**Double-click** to select a word  
**Triple-click** to select a line  
**Ctrl+A** to select everything  

**Selection Tips:**
- See character count when text is selected (collapsed mode)
- Copy/Cut/Paste show visual feedback
- Escape to clear selection

### Word-Level Editing

**Delete entire words faster:**
- `Ctrl+Backspace` - Delete word backward
- `Ctrl+Delete` - Delete word forward
- `Ctrl+Shift+K` - Clear entire input

---

## 🖼️ Working with Attachments

### Adding Attachments
- Drag and drop files
- Click the + button and choose upload
- Paste images directly (`Ctrl+V`)

### Managing Attachments
- **Undo adding**: Press `Ctrl+Z` after adding
- **Remove one**: Click X on the attachment
- **Remove all**: Press `Ctrl+Shift+X` or click "Clear All"
- **Undo removal**: Press `Ctrl+Z` to restore

## 🎯 Two Modes Explained

### Collapsed Mode (Default)
**When to use:** Quick questions, short messages

**Features:**
- Single line input
- Enter sends immediately
- Minimal, clean interface
- Plus button for quick actions

**Shortcuts:**
- `Enter` to send
- `Ctrl+E` to expand

### Expanded Mode
**When to use:** Long messages, detailed questions

**Features:**
- Multi-line input
- Character counter
- More shortcuts visible
- Better for editing

**Shortcuts:**
- `Shift+Enter` to send
- `Ctrl+E` or `Escape` to collapse

---

## 💡 Pro Tips

### Keyboard-First Workflow

```
1. Ctrl+E          → Expand input
2. Type message    → Write your question
3. Ctrl+V          → Paste image (if needed)
4. Shift+Enter     → Send
5. Ctrl+H          → Hide window when done
```

### Recovering from Mistakes

**Made a mistake?**
- `Ctrl+Z` until you get back to where you want
- `Ctrl+Y` if you went too far back

**Accidentally cleared everything?**
- `Ctrl+Z` brings it all back (text + attachments!)

**Pasted wrong thing?**
- `Ctrl+Z` to undo paste
- `Ctrl+V` to paste the right thing

### Efficiency Tricks

1. **Type to focus** - Start typing anywhere, input focuses automatically
2. **Quick clear** - `Ctrl+Shift+K` to start fresh
3. **Quick hide** - `Ctrl+H` when you're done
4. **Theme switch** - `Ctrl+T` for dark/light theme

### What to Expect

**Toast Notifications:**
- Top center: "Undo", "Redo", "Copied!", etc.
- Auto-disappear after 1-2 seconds
- Red for errors, normal for info

**Selection Hints:**
- Bottom right: Character count when text selected
- Only in collapsed mode

**Character Counter:**
- Visible in expanded mode
- Shows live count as you type

## ❓ Getting Help

### Built-in Help

**Keyboard Shortcuts Modal:**
- Press `Ctrl+/` or `F1`
- Shows all available shortcuts
- Organized by category
- Click outside or press Escape to close

**Button Tooltips:**
- Hover over any button
- See what it does + keyboard shortcut
- Example: Expand button shows "(Ctrl+E)"

**Help Hint:**
- Appears first time you use the app
- Shows how to open shortcuts modal
- Won't show again after you've seen it

## 🔍 Troubleshooting

### Common Issues

**"Nothing happens when I press Ctrl+Z"**
→ Make sure you're not in a modal or dropdown
→ Try clicking the input first

**"My shortcut doesn't work"**
→ Check if you're in the MCP modal or settings
→ Some shortcuts only work when input is focused

**"I can't see my selection"**
→ Selection color may be subtle in some themes
→ Try changing theme with `Ctrl+T`

**"Character counter not showing"**
→ Only visible in expanded mode
→ Press `Ctrl+E` to expand

### Need More Help?

1. Press `Ctrl+/` for all shortcuts
2. Check `UX_IMPROVEMENTS.md` for detailed docs
3. Hover buttons for quick tooltips

## 🎓 Practice Exercises

### Exercise 1: Basic Undo/Redo
1. Type: "The quick brown fox"
2. Press `Ctrl+Z` (text disappears)
3. Press `Ctrl+Y` (text comes back)
4. ✅ You've mastered undo/redo!

### Exercise 2: Word Deletion
1. Type: "Hello beautiful world"
2. Place cursor after "beautiful"
3. Press `Ctrl+Backspace` (deletes "beautiful")
4. Press `Ctrl+Z` (brings it back)
5. ✅ You're a word-editing pro!

### Exercise 3: Attachment Undo
1. Drag an image to the input
2. Press `Ctrl+Z` (image removed)
3. Press `Ctrl+Y` (image back)
4. ✅ Attachments are undoable!

### Exercise 4: Quick Workflow
1. `Ctrl+E` to expand
2. Type a message
3. `Ctrl+A` to select all
4. `Ctrl+C` to copy
5. `Ctrl+Shift+K` to clear
6. `Ctrl+V` to paste
7. `Shift+Enter` to send
8. ✅ You're efficient!
